# Notebooks

- `01_Prepare_Datasets.ipynb` inspects registered datasets, preprocesses one, and demonstrates MCAR/MAR/MNAR generation.
- `02_Run_Experiment.ipynb` runs the full experiment pipeline with editable settings.
- `03_Legacy_Diabetes_Experiment.ipynb` accesses the historical pre-amputated Diabetes artifacts from the original repository.

Run notebooks with the repository root or `notebooks/` as the working directory.
