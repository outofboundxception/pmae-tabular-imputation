## Decisions

- Online News: remove `url` identifier and `shares` prediction target.
- Adult: concatenate the official training and test files. Strip the trailing full stop from test labels. Handle `?` as pre-existing missing values and record fill counts.
- Credit Default: the original `.xls` is retained. A converted `.xlsx` copy is included for straightforward reading without legacy XLS readers. Drop `ID` and the default-payment target. The configured categorical columns are SEX, EDUCATION, MARRIAGE and the six PAY status fields.
- Online Shoppers: remove Revenue; encode Month, OperatingSystems, Browser, Region, TrafficType, VisitorType and Weekend as categorical.
- Letter Recognition: remove the letter class and use the 16 numeric attributes.
- Bike Sharing: daily/hourly are separate variants. Remove instant/date identifiers and rental count outcomes (`casual`, `registered`, `cnt`).
- Obesity: remove NObeyesdad and encode the eight discrete/text attributes categorically.
- Wine Quality: red and white are separate; remove quality as the supervised target.
- Diabetes: load predictors and target from scikit-learn; the target is excluded.

Adult contains 6,465 source-missing cells represented by `?`. These cells are kept in the model input as missing values; they are not included in the synthetic evaluation mask. The other bundled variants have no source-missing feature cells in the supplied files.

Categorical codes are stable sorted ordinal mappings. The current PMAE architecture is scalar-valued, so this is a compatibility encoding rather than a native categorical model. See README for limitations.
